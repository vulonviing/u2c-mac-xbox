# 09 — Remote Play

Idea: the controller connects to the Mac over Bluetooth and the Mac sends input to the console over the local network with Xbox Remote Play. To play on the TV the console's video output has to stay on.

- On the console, remote features must be on and the power mode set to "instant-on".
- There is the official browser Remote Play and open-source clients like Greenlight/XStreaming. All `[NOT TRIED]`.
- A PR/report said some macOS versions of Greenlight ignore controller input `[SECONDHAND, UNVERIFIED]`.
- Latency depends on your network; not measured.
