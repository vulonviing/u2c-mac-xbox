# Security and privacy

- Do **not** paste serial numbers, MAC/Bluetooth addresses, pairing keys, backup files, raw hex dumps, user names/local paths or names of your other devices into issues or PRs.
- If you pasted something by mistake, edit it out; delete the issue if needed and let us know.
- Before sharing output, run `python3 scripts/redact.py < raw.md > clean.md` and verify with `--check`.
- For security reports use GitHub "Private vulnerability reporting" (repo Security tab). Do not send them by email.
